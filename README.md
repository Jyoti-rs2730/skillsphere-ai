
🚀 SkillSphere AI
AI-Powered Skill Intelligence & Placement Analytics Platform

✨ Project Features
🔹 What the Platform Can Do
📊 Track student skills, projects, certifications, and internships
🧠 Perform AI-based skill gap analysis
👨‍🏫 Enable mentor review and approval system
🎯 Generate placement readiness score
📈 Provide placement analytics and student filtering
🤖 Support job matching and career guidance
📁 Manage complete student digital portfolio

🔹 Technologies Used
Frontend:
HTML, CSS, JavaScript
Chart.js (for interactive dashboards)
Backend:
Node.js & Express.js
JWT (Authentication)
Bcrypt (Password Security)
Multer (File Upload Handling)
Database:
MongoDB Atlas
Tools:
Git & GitHub
VS Code
Postman
Nodemon

⚙️ How to Install & Run the Project
Step 1: Extract the File
Right-click .rar file
Click Extract Here (WinRAR / 7-Zip)
Step 2: Open in VS Code
Open extracted folder in VS Code
Step 3: Install Dependencies
npm install
Step 4: Start Backend Server
npm start

OR

nodemon server.js
Step 5: Run Frontend
Open index.html in browser
Or use Live Server
Step 6: Use the Application
Login as:
Student
Mentor
Placement Officer
Explore:
Dashboards
Skill tracking
Mentor review
Placement analytics
